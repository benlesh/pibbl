# CRC library status and feature inventory

_Current feature inventory refreshed 2026-09-15 after WebGL lighting,
materials, background, orbit-camera, and genuine-shadow implementation.
Historical totals remain evidence only for their named dated revision; run the
trust gate for current results._

## At a glance

CRC is a scheduled immediate-mode Canvas component runtime with an optional
WebGL-island package. Its preferred surface is automatic JSX over opaque
branded elements; `createElement` is the complete non-JSX equivalent. Ordinary
components are synchronous functions. Canvas 2D and WebGL components share one
tree, scheduler, JSX runtime, paint ledger, and event path. CRC has no React
dependency and creates no DOM.

Current evidence covers source/built/packed package boundaries, Bundler and
NodeNext declarations, both compiler entries, mixed CRC/React type boundaries,
65 cataloged learning lessons, 21 cataloged deterministic laboratories,
semantic and geometry
assertions, browser behavior, lifecycle ownership, Studio builds, and guarded
visual baselines. Controlled wall-clock budgets remain opt-in; deterministic
workload structure is always checked.

## Public feature inventory

### Authoring, runtime, and identity

| Feature                        | Supported contract                                                                                                                                                                                                                                                            | Boundary                                                                                                             |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Automatic JSX                  | **Trusted.** Root and compiler subpaths provide branded elements, module-scoped JSX types, source metadata, required props/style/children checks, and no lowercase intrinsics.                                                                                                | One file has one JSX runtime; the classic transform is not documented.                                               |
| `createElement`                | **Trusted.** Same descriptors and runtime behavior as JSX; null props, variadic-child precedence, keys, arrays, text, policies, and mounting are covered.                                                                                                                     | Direct component calls do not create elements.                                                                       |
| Plain functions                | **Trusted.** One props argument, synchronous node/void return, function identity, hook lifecycle, arbitrary recursive return nodes, and error recovery are covered.                                                                                                           | Async/Promise components reject.                                                                                     |
| `CRCElement` / `CRCNode`       | **Trusted.** Opaque global-symbol brand, nominal typing, key normalization/removal, development freezing/source, recursive arrays/finite iterables/empty roots, and foreign-element rejection.                                                                                | Iterables must be finite. Raw non-empty text/nonzero numbers belong inside `Text`.                                   |
| Fragments, lists, keys         | **Trusted.** Transparent arrays/unkeyed fragments, keyed-fragment scope, duplicate diagnostics, keyed reorder, and unkeyed occurrence identity are direct contracts.                                                                                                          | Keys preserve identity only under the same parent.                                                                   |
| `crc(canvas, root, config?)`   | **Trusted.** One live mount, coalesced latest-root updates, fixed/responsive surfaces, stable controller, abort, idempotent disposal, and stale-controller safety.                                                                                                            | Mount configuration belongs to the first live mount.                                                                 |
| Signals                        | **Trusted.** Explicit `get()`, writable/readonly views, function-valued data, lazy dynamic computed graphs, equality, untracked reads, computed-only Plan liveness, observation-aware source edges, component consumers, write guards, and exact cleanup are covered.         | Signals never unwrap implicitly; unobserved computed graphs retain version snapshots without source observer leases. |
| Realm scheduler                | **Trusted.** One pending frame across roots/Layers, six ordered phases, staged-only Advance mutation, explicit Commit/Plan admission, phase deferral, stable non-fail-fast Plan validation, root order, nested Layer revisions, error isolation, and completions are covered. | Realm-wide means one loaded runtime; it is not a retained scene graph or worker scheduler.                           |
| Animation definitions/programs | **Trusted.** Numeric tweening, keyframes, analytic springs, custom seekable definitions, fixed-step state, immutable composition, duration/overlap validation, milestones, repeats, and whole-run writer leases are covered.                                                  | Nonnumeric interpolation is explicit; definitions/programs own no clock and there is no free `play`.                 |
| Playback and transitions       | **Trusted.** Component-owned controls, statuses, logical-time sampling, atomic writes/replacement, retarget continuity, callback ordering, failure isolation, and teardown are covered.                                                                                       | Ordinary style receives explicit `.get()` values; CRC exposes no public realm clock/history.                         |
| Hooks and failure              | **Trusted.** Slot order, state/signal/memo/ref/change cleanup, path/event/cursor hooks, Canvas/layout accessors, fail-closed cleanup, and valid retry are covered.                                                                                                            | Earlier pixels in a failing frame are not rolled back.                                                               |

| `Clip`                                         | **Trusted.** Multi-child `nonzero`/`evenodd` clips, cumulative intersections, updates, and identical paint/hit geometry.                                                                                                                                                                                 | No retained clip object is public.                                                                                                             |
| `Layer`                                        | **Trusted.** Multi-child persistent offscreen instance, one-shot direct iterable input, revisioned deepest-first invalidation, clean-sibling cache hits, density, global paint/target/focus order, and cascading cleanup.                                                                                | Requires browser `OffscreenCanvas`; retained equality is intentionally shallow/structural.                                                     |
| `WebGLLayer`                                   | **Trusted.** One persistent WebGL2 island composes and settles a frame-local scene, reuses or renders genuine shadow-depth generations, renders color queues, then transactionally commits matching bitmap/pick/focus metadata; layout, caching, context restoration, and exact teardown remain covered. | The island composites as one Canvas item; Canvas and WebGL subprimitives cannot interleave inside it.                                          |
| `Group3D`, `Mesh`, `Cube`, `Sphere`            | **Trusted.** Transform/listener scopes and immutable normal-aware mesh submissions share geometry/model/camera/source facts across Lambert/unlit rendering, shadow participation, opaque/transparent queues, depth-aware picking, and projected focus bounds.                                            | One object-level transparent sort is not order-independent transparency; there is no retained public scene graph.                              |

| Canvas and WebGL particle effects              | **Trusted.** Immutable definitions, deterministic descriptors, component-owned systems, fixed Canvas storage, manual Canvas bursts, and stateless instanced WebGL points/billboards share the realm scheduler and exact ownership evidence.                                                              | Stateful WebGL, manual WebGL births, world space, distance sorting, and public shaders remain deferred.                                        |
| Genuine WebGL shadows                          | **Trusted.** Direct lights and opaque meshes participate by default; layer-wide disabled/low/medium/high quality uses directional/spot 2D maps and point six-face cube maps, independently attenuates each direct contribution, and reuses valid depth across camera-only changes.                       | No cascades, soft/contact/transparent shadows, public shadow cameras, bias, map sizes, or pass callbacks.                                      |
| `style.filter`                                 | **Trusted.** Ten typed Canvas filter descriptors, single/list/empty forms, combined-subtree silhouettes, ordered lists, inside-out nesting, upright local capture, Group/Clip/Layer order, density, edge expansion, interaction isolation, pooling, and failure cleanup.                                 | Nonempty filters require browser `OffscreenCanvas` plus Canvas `filter`; raw strings, `url()`, backdrop filters, and `boxShadow` are excluded. |

## Running locally

Use Node 24.15.0 or newer on the Node 24 LTS line and pnpm 11.21.0:

```sh
corepack pnpm@11.21.0 install --frozen-lockfile --strict-peer-dependencies
corepack pnpm@11.21.0 exec playwright install chromium
corepack pnpm@11.21.0 playground
corepack pnpm@11.21.0 trust
```

See the [trust-gate guide](./testing/trust-gate.md) for command/evidence
semantics.
