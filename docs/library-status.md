# CRC library status and feature inventory

_Current feature inventory refreshed 2026-09-29 after the full Three.js pivot.
Historical totals remain evidence only for their named dated revision; run the
trust gate for current results._

## At a glance

CRC is a scheduled immediate-mode Canvas 2D component runtime. Its preferred
surface is automatic JSX over opaque branded elements; `createElement` is the
complete non-JSX equivalent. Ordinary components are synchronous functions.
CRC has no React dependency and creates no DOM.

External renderers integrate through public `defineRenderLayer()`.
`@crc/three` is the official thin adapter: applications use ordinary Three.js
scenes, cameras, objects, controls, loaders, materials, lighting, shadows,
particles, and post-processing while CRC owns outer composition, shared
scheduling, event/focus arbitration, filters, and teardown. The former custom
WebGL scene package, WebGL particle entry, and renderer-coupled 3D physics
runtime are removed. Pure `@crc/core/physics/3d/geometry` remains.

Current evidence covers source/built/packed package boundaries, Bundler and
NodeNext declarations, both compiler entries, mixed CRC/React type boundaries,
59 cataloged learning lessons, 24 cataloged deterministic laboratories,
semantic and geometry assertions, browser behavior, lifecycle ownership, Studio
builds, and guarded visual baselines. Controlled wall-clock budgets remain
opt-in; deterministic workload structure is always checked.

First-class filter evidence is anchored by the [implemented design
record](./superpowers/specs/2026-09-08-first-class-filters-design.md), current
[style](./design/style-system-contract.md),
[drawing](./design/drawing-components-contract.md),
[surface](./design/canvas-surface-contract.md), and
[ownership](./design/runtime-resource-ownership.md) contracts, the public
[`filters` lesson](../packages/scenarios/src/learning/composition/filters.example.tsx),
and its browser, ownership, and structural-performance suites.

External render-layer and Three.js evidence is anchored by the current
[render-layer and Three.js contract](./design/render-layer-and-three-contract.md),
the approved [full-pivot
record](./superpowers/specs/2026-09-28-three-full-pivot-design.md), the public
[`three-layer`](../packages/scenarios/src/learning/three/three-layer.example.tsx)
and [`three-instancing`](../packages/scenarios/src/learning/three/three-instancing.example.tsx)
lessons, focused core/adapter suites, source and built Studio builds, and packed
Bundler/NodeNext consumers.

First-class signal, scheduler, and animation evidence is defined by the
[signals and scheduling contract](./design/signals-and-scheduling-contract.md),
the [animation contract](./design/animation-contract.md), the updated
[runtime](./design/runtime-hooks-contract.md),
[surface](./design/canvas-surface-contract.md), and
[ownership](./design/runtime-resource-ownership.md) contracts, and focused
signal graph, component-consumer, hook, scheduler, definition, composition,
playback, transition, Layer, error-isolation, package-consumer, and Studio
declaration suites.

Renderer-independent 3D physics evidence is limited deliberately to immutable
shape construction and pure geometry/query operations from
`@crc/core/physics/3d/geometry`. CRC currently ships no 3D world, presentation,
scheduler lane, or Three binding.

“Trusted” below means the supported behavior, boundaries, errors, updates, and
teardown have executable evidence. It does not mean CRC supplies semantic DOM,
an accessibility tree, hidden editing controls, rich text, scrolling, or
complete CSS.

## Public feature inventory

### Authoring, runtime, and identity

| Feature                        | Supported contract                                                                                                                                                                                                                                                                     | Boundary                                                                                             |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Automatic JSX                  | **Trusted.** Root and compiler subpaths provide branded elements, module-scoped JSX types, source metadata, required props/style/children checks, and no lowercase intrinsics.                                                                                                         | One file has one JSX runtime; the classic transform is not documented.                               |
| `createElement`                | **Trusted.** Same descriptors and runtime behavior as JSX; null props, variadic-child precedence, keys, arrays, text, policies, and mounting are covered.                                                                                                                              | Direct component calls do not create elements.                                                       |
| Plain functions                | **Trusted.** One props argument, synchronous node/void return, function identity, hook lifecycle, arbitrary recursive return nodes, and error recovery are covered.                                                                                                                    | Async/Promise components reject.                                                                     |
| `CRCElement` / `CRCNode`       | **Trusted.** Opaque global-symbol brand, nominal typing, key normalization/removal, development freezing/source, recursive arrays/finite iterables/empty roots, and foreign-element rejection.                                                                                         | Iterables must be finite. Raw non-empty text/nonzero numbers belong inside `Text`.                   |
| Fragments, lists, keys         | **Trusted.** Transparent arrays/unkeyed fragments, keyed-fragment scope, duplicate diagnostics, keyed reorder, and unkeyed occurrence identity are direct contracts.                                                                                                                   | Keys preserve identity only under the same parent.                                                   |
| `crc(canvas, root, config?)`   | **Trusted.** One live mount, coalesced latest-root updates, fixed/responsive surfaces, stable controller, abort, idempotent disposal, and stale-controller safety.                                                                                                                     | Mount configuration belongs to the first live mount.                                                 |
| Signals                        | **Trusted.** Writable/readonly views, declared receiver-owned inputs, explicit parent reads, function-valued data, batching, lazy dynamic computed graphs, equality barriers, untracked reads, reactions, observation-aware source edges, write guards, and exact cleanup are covered. | Resolution is shallow and schema-declared; arbitrary application data is never deep-unwrapped.       |
| Realm scheduler                | **Trusted.** One pending frame across roots/Layers, six ordered phases, staged-only Advance mutation, explicit Commit/Plan admission, phase deferral, stable non-fail-fast Plan validation, root order, nested Layer revisions, error isolation, and completions are covered.          | Realm-wide means one loaded runtime; it is not a retained scene graph or worker scheduler.           |
| Animation definitions/programs | **Trusted.** Numeric tweening, keyframes, analytic springs, custom seekable definitions, fixed-step state, immutable composition, duration/overlap validation, milestones, repeats, and whole-run writer leases are covered.                                                           | Nonnumeric interpolation is explicit; definitions/programs own no clock and there is no free `play`. |
| Playback and transitions       | **Trusted.** Component-owned controls, statuses, signal-valued inputs, logical-time sampling, atomic writes/replacement, retarget continuity, callback ordering, failure isolation, and teardown are covered.                                                                          | CRC exposes no public realm clock/history.                                                           |
| Hooks and failure              | **Trusted.** Slot order, signals/computed/const/ref/reaction cleanup, path/event/cursor hooks, Canvas/layout accessors, fail-closed cleanup, and valid retry are covered.                                                                                                              | Earlier pixels in a failing frame are not rolled back.                                               |

| `Text`                                         | **Trusted.** Recursive textual children including zero, one-shot iterable materialization, exact concatenation, wrapping/fit/clipping, shared measurement/paint, multiline targets, and updates.                                                                         | Font metrics/rasterization are platform-dependent; elements are invalid textual content.                                                       |

| `Clip`                                         | **Trusted.** Multi-child `nonzero`/`evenodd` clips, cumulative intersections, updates, and identical paint/hit geometry.                                                                                                                                                 | No retained clip object is public.                                                                                                             |
| `Layer`                                        | **Trusted.** Multi-child persistent offscreen instance, one-shot direct iterable input, revisioned deepest-first invalidation, clean-sibling cache hits, density, global paint/target/focus order, and cascading cleanup.                                                | Requires browser `OffscreenCanvas`; retained equality is intentionally shallow/structural.                                                     |
| `defineRenderLayer`                            | **Trusted.** One mounted identity owns one external resource lifetime, shared CRC frame input, finite logical/backing size, transactional bitmap/interaction publication, miss policy, focus metadata, and exact teardown.                                               | One layer is one flattened Canvas item; renderer subprimitives cannot interleave with Canvas siblings.                                         |
| `defineThreeLayer`                             | **Trusted.** One adapter-owned transparent Three renderer hosts ordinary application-owned scenes/cameras, default rendering and raycasting, registered targets, blocking geometry, routed controls input, invalidation, and deterministic cleanup.                      | CRC does not wrap or reconcile Three objects, materials, lights, loaders, shadows, particles, or post-processing.                              |
| Canvas particle effects                        | **Trusted.** Immutable 2D definitions, deterministic descriptors, component-owned systems, fixed Canvas storage, scheduled/manual births, shared realm scheduling, and exact ownership evidence.                                                                         | CRC exposes no parallel 3D/WebGL particle vocabulary; Three applications use Three facilities directly.                                        |
| Pure 3D physics geometry                       | **Trusted.** Immutable shapes and renderer-independent bounds, mass, containment, distance, overlap, contact, ray-cast, shape-cast, and transform operations are covered.                                                                                                | No renderer-coupled 3D world, presentation, scheduler lane, or Three binding is currently public.                                              |
| `style.filter`                                 | **Trusted.** Ten typed Canvas filter descriptors, single/list/empty forms, combined-subtree silhouettes, ordered lists, inside-out nesting, upright local capture, Group/Clip/Layer order, density, edge expansion, interaction isolation, pooling, and failure cleanup. | Nonempty filters require browser `OffscreenCanvas` plus Canvas `filter`; raw strings, `url()`, backdrop filters, and `boxShadow` are excluded. |

### Style, layout, and extension

| Feature                             | Supported contract                                                                                                                                                                                    | Boundary                                                                                 |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Explicit local style                | **Trusted.** Closed per-component schemas, specified/normalized/resolved stages, finite diagnostics, no legacy aliases, and no content/structural leakage into style.                                 | No cascade, inheritance, selectors, margin, or complete CSS parser.                      |
| `Absolute`                          | **Trusted.** Definite child size, number/percentage offsets, padding, clipping, nesting, source order, and identity across reflow.                                                                    | No right/bottom anchors or automatic placement.                                          |
| `Overlay`                           | **Trusted.** Shared allocation, container/self alignment, stretch/oversize behavior, clipping, and overlap order.                                                                                     | Definite child size; no z-index.                                                         |
| `Flow`                              | **Trusted.** Horizontal/vertical sequential layout, optional wrapping, gaps, alignment, pure measurement, and used-size rendering.                                                                    | CRC-native; no inline shaping, reverse, justification, or baseline.                      |
| `Flex`                              | **Trusted.** Supported row/column, nowrap/wrap, grow/shrink/minimums, gaps, distribution/alignment, and DOM-oracle parity.                                                                            | Reverse/order/baseline/auto margins/percentage gaps and advanced intrinsic cases reject. |
| `Grid`                              | **Trusted.** Explicit fixed/percentage/fractional tracks, one-based starts/spans, gaps, alignment, overlap, clipping, and DOM-oracle parity.                                                          | No implicit/auto placement, content tracks, repeat/minmax, areas, or subgrid.            |
| `measureElement` / `useLayoutBox`   | **Trusted.** Pure isolated measurement, cycles, text/custom measurement, explicit image size, stable finite local allocations, and no ownership.                                                      | Plain components and ambiguous intrinsic layout report unsupported.                      |
| `useCanvasContext`                  | **Trusted.** Current isolated context during render, no hook slot, save/restore and failure behavior.                                                                                                 | Unavailable outside rendering and during pure measurement.                               |
| `definePrimitive`                   | **Trusted.** Reserved program props, required/optional specified style, normalize/resolve/measure capabilities, finite allocation enforcement, and private metadata.                                  | Platform extension only; ordinary components should use plain functions.                 |
| External render layers and Three.js | **Trusted.** `defineRenderLayer` exposes the renderer-neutral lifecycle; `defineThreeLayer` provides a thin ordinary-Three adapter with CRC scheduling, picking, controls input, focus, and teardown. | External resources remain application-owned; CRC defines no Three JSX scene vocabulary.  |

### Events, focus, and accessibility boundary

| Feature                               | Supported contract                                                                                                                                                                                                                             | Boundary                                                                                             |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Built-in event props                  | **Trusted.** DOM-aligned pointer, mouse, touch, wheel, keyboard/focus, editing/composition, clipboard, and drag/drop facades with propagation, cancellation, related targets, and pointer capture.                                             | Native non-coordinate input needs a current logical target.                                          |
| Default drawing targets               | **Trusted.** Canvas drawing primitives and committed render-layer targets participate by default; `pointerEvents="none"` is the explicit visual-only opt-out. Blocking layer hits can occlude lower Canvas targets without inventing handlers. | Empty pixels follow the layer's explicit pass-through, block, or target-layer miss policy.           |
| Render-layer event bridge             | **Trusted.** One reverse global ledger delegates a layer slot to its bitmap-matched interaction resolver, then resumes lower Canvas candidates on miss. | Three controls input                  | **Trusted.** The adapter supplies controls with CRC-routed pointer, wheel, context-menu, click, and pointer-capture behavior; controls invalidate the shared layer when another frame is needed.                                               | Controls install no independent Canvas listeners or animation loop.                                  |
| `useEventTarget` / `useEventListener` | **Trusted.** Explicit geometry, transforms/clips, stable target identity, propagation listeners, focus metadata, mutation isolation, and exact teardown.                                                                                       | Geometry is never inferred from returned descendants.                                                |
| `useEvent` / `useCursor`              | **Trusted.** Geometric legacy hook behavior, pathless Canvas observers/default cursors, target precedence, replacement, and exact ownership.                                                                                                   | Pathless observer payload remains the narrow shipped mouse shape.                                    |
| `FocusManagement`                     | **Trusted.** Transparent exactly-one-child policy, one Canvas host, candidate enrollment, logical focus events/snapshots, source-order Tab, press focus, activation, focus-visible state, layer invalidation, and cleanup.                     | Keyboard interaction does not create semantics or an accessibility tree.                             |
| `KeyboardNavigation`                  | **Trusted.** Transparent directional boundaries, finite geometry ranking, nested containment, prevented keys, and source-order Tab independence.                                                                                               | Directional mode does not wrap or escape an inner boundary edge.                                     |
| Accessibility                         | **Explicit application boundary.** Guidance requires an equivalent semantic DOM experience synchronized with the Canvas model.                                                                                                                 | CRC generates no semantic descendants, roles, names, editing controls, or assistive-technology tree. |

current guide/contract and executable repository evidence. `docs:check`
validates exact semantic mappings, link anchors, example extensions,
fail-closed API inventory, extracted complete programs, compiler transforms,

this covers 19 current normative contracts. The six mapped records contain 204
exhaustively mapped post-baseline units. The evidence inventory contains 56 unique direct
source/test mappings. It also inspects the cited examples/tests for the
behaviors claimed in the Text, Layer, focus, and complete non-JSX rows;

## Running locally

Use Node 24.15.0 or newer on the Node 24 LTS line and pnpm 11.21.0:

```sh
corepack pnpm@11.21.0 install --frozen-lockfile --strict-peer-dependencies
corepack pnpm@11.21.0 exec playwright install chromium
corepack pnpm@11.21.0 playground
corepack pnpm@11.21.0 trust
```

See the [trust-gate guide](./testing/trust-gate.md) for command/evidence
semantics.
