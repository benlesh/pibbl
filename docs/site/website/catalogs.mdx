Choose a building block, inspect its output, and follow its reference or runnable source. This collection contains one entry per category; remaining shapes, filters, and generators are not yet migrated.

| Catalog            | First entry                                           | What it demonstrates                           |
| ------------------ | ----------------------------------------------------- | ---------------------------------------------- |
| Shapes             | [Circle](/catalogs/shapes/circle/)                    | Center, radius, and fill                       |
| Filters            | [Blur comparison](/catalogs/filters/blur/)            | Identical geometry with and without pixel blur |
| Textures           | [Marble](/catalogs/textures/marble/)                  | A deterministic static material                |
| Reaction-diffusion | [Living button](/catalogs/reaction-diffusion/button/) | A living texture behind native HTML            |

These are CRC output examples, not a proposed visual identity for this site. The static descriptions and source remain readable without JavaScript. Optional live previews let you inspect Canvas output; the native button has a CSS fallback.
