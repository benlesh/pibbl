Pibbl is a component runtime for Canvas 2D. Author drawing with synchronous functions, use signals to update it, and compose effects without managing a separate animation loop.

- [Build with Pibbl](/start/): install the runtime and draw your first scene.
- [Add Pibbl to your site](/guides/add-to-your-site/): keep your HTML application and enhance one visual region.

## Explore the library

The [reference](/reference/) brings the existing public API documents into capability groups and an alphabetical index. The [guide library](/guides/) covers authoring, lifecycle, layout, animation, textures, input, physics, visualization, and Three.js. [Detailed agent topics](/agents/) explain implementation decisions, failure modes, and verification.

The visual collection remains intentionally small: Circle, blur, marble, a native HTML button with reaction-diffusion, and Stirred Ink. More visual examples and design work follow separately. Existing Studio examples remain available through the [playground](/playground/).
