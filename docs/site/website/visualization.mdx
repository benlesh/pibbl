Build charts with `@pibbl/core/viz`: scales, axes, data marks, inspection, and navigation that compose with Pibbl layout, signals, animation, and events. Start with a complete example, change its data in the playground, then follow the API links for precise behavior. No required chart container or separate animation loop.

## Interaction, inspection, and navigation

Use [HoverData](/reference/components/hover-data/) for explicit data queries and [rendered-series inspection](/reference/functions/rendered-series-inspection/) to query captured geometry through the optional `@pibbl/core/viz/inspection` entry. Read [ScaleAdjust](/reference/components/scale-adjust/) for domain navigation, [chart guides](/reference/components/chart-lines/) for references, and [chart editing](/reference/components/chart-editing/) for controlled edits.

Keep labels, units, missing observations, and baselines meaningful. Provide an application-owned HTML summary or table for important Canvas information. The [agent visualization guide](/agents/topics/visualization/) covers coordinate conversion, ownership, and verification.
