This application recipe uses the supported `stripes` preset with seed 42, a 128 by 48 simulation, and a dark teal palette. It is one presentation of reaction-diffusion, not a new Pibbl component or simulation algorithm.

The native button remains the only interactive target. Pointer movement drags and paints the ink along its path. Clicking creates a ring-shaped paint burst with outward stirring at the pointer; keyboard activation centers the burst. Hover and focus also seed the field. The simulation pauses while disabled, hidden, offscreen, or when reduced motion is requested.

[Run the complete button recipe](/guides/native-button/) to see the actual result, disable the button, and remove/remount its effect. The page includes all HTML, CSS, and JavaScript. Without JavaScript, the native label and CSS background remain visible.
