## Interactive showcases

- [Rainy Window](/examples/rainy-window/): wipe fogged glass, gather droplets, and watch rain refract the city.
- [Plasma Globe and Lightning](/examples/plasma-globe/): interact with electric tendrils and independent lightning textures.
- [Enter and Exit Transitions](/examples/visibility-transitions/): compare reusable presets, reverse them, and exit before unmounting.
- [Energy Transition Study](/examples/energy-transitions/): the original tunable beam, hologram, and ember study.

## Larger composition

[Stirred Ink](/examples/stirred-ink/) combines procedural materials, an animated setting, a 2D physics body, and a reaction-diffusion field. The page provides its full existing source and links to the working editor. Its complexity makes it a showcase, not the recommended first integration.

This is a curated first collection. More examples remain in the existing Studio; their presence there does not imply they have been migrated or reviewed as part of this website slice.
