# Pibbl Big Bubbles logo kit

The approved Original Tangram with two interior bubble cutouts and an organic cloud of nine dots. Vivid coral #FF735E, Kelly green #159447, soft violet #8B5CCB. Version 2.0, October 8, 2026.

Start with svg/pibbl-horizontal-color.svg for light backgrounds, or svg/pibbl-horizontal-color-on-dark.svg for dark backgrounds. Use svg/pibbl-icon-color.svg without lettering. index.html is the visual catalog; Pibbl-Big-Bubbles-Brand-Guide.pdf contains usage guidance.

## Included

- Horizontal, stacked, icon-only and wordmark-only arrangements, in full color, full color with white lettering, black and white.
- Editable, self-contained SVG masters with outlined lettering. Cutouts remain transparent on any background.
- Transparent PNGs in multiple sizes, up to 4096 px wide for horizontal logos and 2048 px for icons.
- 16 vector PDF and 16 vector EPS print masters. These use RGB artwork; proof the intended print profile and stock before production.
- Favicon SVG, ICO and 16/32/48 px PNGs, app/touch icons, maskable icon, WebP and web manifest.
- Four profile images; light/dark share cards, banners, slide covers, square posts and wallpapers; geometric patterns, sticker artwork and email signature logo.
- Separate solid shapes, final bowl with cutouts, nine individual bubbles, and outlined wordmark for the future animation. Exact paths, pivots and bubble release positions are recorded in animation/animation-parts.json.
- CSS/JSON color tokens, reproducible builders, asset catalog, checksums and delivery manifest.

## Usage

Use the full-detail icon at 64 px high or larger; horizontal logo at 240 px wide or larger; stacked at 160 px wide; wordmark at 100 px wide. Browser favicons intentionally use the three solid Tangram shapes without tiny bubbles or cutouts. Keep at least 35 master units of clear space around the entire mark, including the outer dots. Do not regenerate random bubble positions; the approved organic arrangement is fixed.

Core SVG and PNG assets have transparent backgrounds. White artwork requires a contrasting background. Marketing exports include their backgrounds. The sticker asset includes a white border; it is artwork, not a vendor-specific technical cut path or bleed specification.

## Future animation

Tumble the three solid shapes in a repeating loading loop, settle them into the P when ready, release bubbles and reveal cutouts, then hold the logo. The kit supplies independent pieces and exact geometry; it does not implement the animation. Coral and green bubbles can transition color during release. See animation/README.md for coordinate details.

## Web installation

Copy web/ into your public asset directory and preserve manifest-relative paths. Reference favicon.ico or favicon.svg, apple-touch-icon.png and site.webmanifest. The manifest includes icon metadata; add app-specific PWA fields as needed. For email use, host the signature image publicly or attach it with a CID and replace the relative image path.

## Reproduction

Run node source/build.mjs with sharp installed, or set PIBBL_SHARP_PATH to its package directory. Run python3 source/build_pdf.py with reportlab installed. Run source/verify.py with Pillow, pypdf and reportlab, followed by source/pack.py to rebuild the manifest, checksums and ZIP. The gallery, README, tokens and animation source assets are handoff files and are not regenerated by these builders.
