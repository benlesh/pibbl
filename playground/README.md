# CRC Playground

An interactive playground for experimenting with CRC (Canvas React Components) library. This playground allows you to write and test CRC components in real-time with a live preview.

## Features

- Split-view editor with live preview
- Monaco editor with TypeScript support
- Pre-built example components
- Real-time rendering
- Custom component creation support

## Development

To run the playground locally:

  ```bash
  # Install dependencies
  pnpm install

  # Start the development server
  pnpm playground:dev
  ```

## Examples

The playground comes with several example components:

1. **Button Example**: A styled button component with hover effects
2. **Vanilla Context Example**: A button using vanilla canvas context
3. **Custom Component**: Template for creating your own components
